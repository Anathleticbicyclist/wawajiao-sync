# 鸣谢、来源与许可说明

哇哇叫（`com.wawajiao.sync`）是开源项目 **迈进OB** 的衍生作品，并参考了 **顽爪爪 WanSync** 的 Strava 上传方案。本文件记录来源、改动范围与许可义务，供使用者与后续维护者核对。

## 一、来源项目

### 1. 鸡翅幸哲迈进OB（代码基底）

- 作者：Anathleticbicyclist
- 仓库：https://github.com/Anathleticbicyclist/marching-ob-manager
- 许可证：MIT
- 提供能力：多平台数据源接入（iGPSPORT、行者、迈金、黑鸟、百锐腾、佳明、高驰、Wahoo、Zwift、Keep 等）、FIT/GPX 解析与时区修正、坐标纠偏、同步引擎、Outbase 上传链路、深色模式与基础 UI 框架。

### 2. 顽爪爪 WanSync（Strava 协议参考）

- 作者：Tyan66666
- 仓库：https://github.com/Tyan66666/WanSync
- 作用：Strava 网页端上传流程（csrf 获取、multipart 提交、进度轮询）的思路与字段组织参考。
- 许可：以该仓库自身声明为准，本项目未直接复制其代码，仅参考协议流程；如后续引入其代码片段，须同步其许可与署名。

## 二、本项目改动范围

相对上游基底，本项目的主要改动：

1. 应用标识：`applicationId` 改为 `com.wawajiao.sync`，版本 `1.0.0` / versionCode `10000`；命名空间保留 `com.jichi.ob`。
2. 新增 Strava 上传目标：`api/StravaApi.kt` + `UploadEngine` 的 Strava 分支 + 去重键 `{源}_{活动id}_to_strava`。
3. 同步目标改为 Outbase / Strava 二选一：设置页单选、单值持久化，`AutoSyncWorker` 跟随所选目标，目标未登录则跳过并通知。
4. 新增 Strava 设置页与自检：带 HTTP 状态码的会话检测、「试传一条」链路自检。
5. UI 品牌化：主题色统一为 `#FC4C02`，关于页改为哇哇叫内容与图标，鸣谢仅保留上述两个开源项目。
6. 增加 JVM 单元测试：`app/src/test/.../api/StravaApiTest.kt`（本地假服务器断言 multipart 字段与轮询三态）。
